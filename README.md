# SWISS100 GDS item non-response

Code and simulated data for the manuscript *Handling item non-response in depression assessments among centenarians: evaluating data replacement techniques in a cross-sectional study with a simulation* (submitted to BMC Geriatrics).

The study describes item non-response in the Geriatric Depression Scale (GDS-15 and GDS-4) among centenarians in the Swiss Centenarian Study (SWISS100), identifies its determinants, and compares scoring strategies (complete-case, Rule-8/Rule-3, sample-mean substitution, ipsative imputation, multiple imputation) in a Monte Carlo simulation.

## Access to the SWISS100 data

The participant-level data are part of the SWISS100 cohort and cannot be shared publicly because of confidentiality and consent restrictions. Access may be requested from the study investigators (https://wp.unil.ch/swiss100/), subject to data-sharing agreements. The Stata do-file expects the file `vulnerability_data_V5_small.dta`, which is not distributed here.

## Files

- `code/01_simulation_synthetic_data_V4.R`: generates the synthetic GDS-15 data (seed 2025) and runs the simulation (100 replications, MCAR, MAR and missing-by-design conditions). Saves `sim_results_V4.rds`.
- `code/02_replot_figures_v5.R`: re-draws the simulation figures from the saved results (`results/2025_09_02_results_sim_syntheticdata.RData`) without re-running the simulation.
- `code/03_stata_empirical_analysis_V7.do`: derivation of the GDS scores and non-response flags, flow-chart counts, Tables 1 to 3, descriptive scores by scoring method. Edit the two paths at the top before running. Requires Stata 18 or later (`dtable`) and the `estout` package.
- `results/`: saved simulation output used for the manuscript figures and Table 4.
- `figures/`: Figures 1 to 4 of the manuscript; `figures/supplementary/` holds the versions showing estimated scores instead of bias.

## Requirements

R 4.4.0 with the packages `mice`, `randomForest`, `dplyr`, `magrittr`, `ggplot2`, `ggstatsplot`, `ggrepel` and `viridisLite`; Stata 19 for the empirical analyses. Platform independent.

## Reproducing the simulation figures

1. Put `2025_09_02_results_sim_syntheticdata.RData` in the working directory (or edit `RDATA` in `code/02_replot_figures_v5.R`).
2. Run `code/02_replot_figures_v5.R`.

To re-run the simulation itself, run `code/01_simulation_synthetic_data_V4.R` (this takes some time).
